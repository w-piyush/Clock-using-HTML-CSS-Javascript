# Analogue Clock
A simple and elegant Analog Clock built using HTML, CSS, and JavaScript that displays real-time updates.

🚀 Live Demo - 

![clock gif](https://github.com/user-attachments/assets/3d37fd48-386b-4643-ab84-941d8148b747)


📌 Features :

 - 🕐 Real-time clock functionality

 - 🎯 Smooth movement of hour, minute, and second hands

 - 💻 Clean and minimal UI

 - 📱 Responsive design



🛠 Tech Stack

 - HTML

 - CSS

 - JavaScript


⚙️ How It Works

 - JavaScript fetches the current system time

 - Calculates rotation angles for:

 - Hour hand

 - Minute hand

 - Second hand

 - Updates the UI every second.
